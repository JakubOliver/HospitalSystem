# Hospital system

## Specification 

Administrative system for hospitals that provides options for managing patients, doctors and appointments. Control by intuitive and seamless terminal user interface. With empathy on effectiveness and atomicity of data operations.  

## How to run

To run the application, navigate to the root `HospitalSystem` directory and execute the command `mvn compile exec:java`.

More detailed information on how to run and control the application can be found in the [User documentation](docs/user.md).
