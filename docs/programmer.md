# Programmer documentation

## Detailed documentation

The detailed documentation of all classes, methods etc. can be generated via using javadoc by executing the following command: `mvn javadoc:javadoc`. After running this command you will find in this `docs/apidocs` directory static webpages with documentation. The main entry point is `docs/apidocs/index.html`.

Or you can visit web page [JavaDocs](https://jakuboliver.github.io/HospitalSystem) where are JavaDocs generated.
